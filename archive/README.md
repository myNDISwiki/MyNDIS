# MyNDIS source archive

This directory contains preserved public source material used by MyNDIS. The
list below names the tracked top-level sites. Each detailed inventory links to
the pages captured within that site.

| Tracked site | Archive inventory |
| --- | --- |
| [NDIS website](https://www.ndis.gov.au/) | [Browsable page index](ndis/index.html) · [XML sitemap](ndis/sitemap.xml) · [capture manifest](ndis/manifest.json) |
| [Health Department NDIS material](https://www.health.gov.au/our-work/ndis-legislation-changes) | [Archive folder and manifest](gov/health/ndis/) |
| [NDIS Commission](https://www.ndiscommission.gov.au/) | [Archive folder and manifest](gov/ndis-commission/) |
| [NDIS Review](https://www.ndisreview.gov.au/) | [Archive folder and manifest](gov/ndis-review/) |
| [Engage NDIS](https://engage.ndis.gov.au/) | [Browsable page index](gov/engage-ndis/index.html) · [capture manifest](gov/engage-ndis/manifest.json) |
| [Australian Parliament NDIS legislation](https://www.aph.gov.au/) | [Configured source records](gov/aph/) |

The archive records source URLs, capture times, hashes, and retrieval status.
It is a preservation and change-detection record; the live government site is
the authoritative source for current information.
