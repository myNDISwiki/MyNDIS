# MyNDIS.wiki Visual Design System & Brand Guidelines

**Project:** MyNDIS.wiki  
**Tagline:** *The People's Guide to the NDIS — A human to human disability resource.*  
**Version:** 1.2 (Draft 3)

## Design direction

MyNDIS is an independent, human-centred information resource. The visual system should feel warm, clear, practical, and trustworthy rather than institutional. Use one responsive system across desktop and mobile widths. The current showcase reference is `design-system-showcase-d17.html`.

## Logo and layout

The primary mark is the transparent heart made from hands. Use `assets/logo-mark.svg` in navy and `assets/logo-mark-white.svg` on green or navy backgrounds. The cropped mark is for prominent display and `favicon.svg` is the browser icon. Do not add glow, gradients, or redraw the mark.

The current header uses a green band with a white logo and title. Desktop menu links use forced uppercase, `600` weight, letter spacing, and a deliberately offset underline. On mobile the links collapse behind a right-aligned menu button. The page canvas is cool off-white and the footer is full-width navy with coral headings and divider.

## Typography hierarchy

- Major page header: serif, `2rem`, bold `700`, navy.
- Section heading: serif, `1.5rem`, bold `700`, navy.
- Lead subheader: body sans-serif, `1.1rem`, semibold `600`, green.
- Body copy: system sans-serif, light/regular `300–400`, line-height `1.65`.
- Italic body: body font, italic, light/regular weight.
- Bold inline: body font, bold, used sparingly.
- Body link: navy, `500`, underlined; hover/focus changes to green with a heavier underline.
- Menu text: uppercase, `600`, letter spacing `0.045em`, underline offset `0.45em`.
- Pull quote: responsive serif bold with balanced padding and optional em-dash attribution.

## Components

Important notices use a coral left border and `#FDF2F0` background. Glossary/key-term callouts use a green left border, `#E6F4EA` background, and a bold green title.

Tables use thin black outlines and internal rules. Headers use navy background, off-white text, serif typography, and bold weight. The first column is left-aligned; all other columns, including headers, are centred. Alternate body rows use `#EEF1F7`.

Keep both subtle 1px divider rules and stronger coloured rules where they communicate different hierarchy. Long-form body copy uses paragraph spacing rather than first-line indentation.

## Versioning

Preserve prior drafts. New revisions use sequential suffixes and must not overwrite earlier files without explicit approval.
