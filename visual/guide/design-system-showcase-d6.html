2. Inline Link States & Lighter Body Typography

This paragraph demonstrates the lighter sans-serif body font weight (300). Body copy is rendered with clean antialiasing for maximum reading comfort across long-form guides.

Inactive Link State: When an inline link is resting in body copy, it uses Navy (#172A52) with a 1.5px solid underline offset: Read the official NDIS Access Requirements Guide.

Active / Hover Link State: When a user hovers or focuses on an inline link, it transitions to Vibrant Green (#2E8C59) with a 2px underline: Explore Section 24 Disability Criteria →.
